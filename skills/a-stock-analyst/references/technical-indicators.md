# 技术指标解读指南

## 移动平均线 (MA)

### 基本概念
移动平均线是将一定时期内的证券价格（指数）加以平均，并把不同时间的平均值连接起来，形成一根 MA。

### 常用周期
- **MA5**: 5 日均线，短期趋势
- **MA10**: 10 日均线，短期趋势
- **MA20**: 20 日均线，中期趋势（月线）
- **MA60**: 60 日均线，中期趋势（季线）
- **MA120**: 120 日均线，长期趋势（半年线）
- **MA250**: 250 日均线，长期趋势（年线）

### 信号解读

| 形态 | 信号 | 含义 |
|------|------|------|
| 多头排列 | 🟢 看涨 | MA5 > MA10 > MA20，上涨趋势确立 |
| 空头排列 | 🔴 看跌 | MA5 < MA10 < MA20，下跌趋势确立 |
| 金叉 | 🟢 看涨 | 短周期 MA 上穿长周期 MA |
| 死叉 | 🔴 看跌 | 短周期 MA 下穿长周期 MA |
| 均线纠缠 | 🟡 观望 | 多条均线粘合，方向不明 |

## MACD (平滑异同移动平均线)

### 组成
- **DIF (快线)**: 短期 EMA 与长期 EMA 的差值
- **DEA (慢线/Signal)**: DIF 的移动平均
- **MACD 柱 (Histogram)**: DIF 与 DEA 的差值

### 信号解读

| 形态 | 信号 | 含义 |
|------|------|------|
| DIF > DEA > 0 | 🟢 强势 | 多头市场，上涨动能强 |
| DIF < DEA < 0 | 🔴 弱势 | 空头市场，下跌动能强 |
| 金叉 (DIF 上穿 DEA) | 🟢 买入 | 尤其是 0 轴上方金叉更可靠 |
| 死叉 (DIF 下穿 DEA) | 🔴 卖出 | 尤其是 0 轴下方死叉更可靠 |
| 顶背离 | 🔴 看跌 | 价格创新高，MACD 未创新高 |
| 底背离 | 🟢 看涨 | 价格创新低，MACD 未创新低 |

### 使用技巧
- MACD 在 0 轴上方为多头市场，下方为空头市场
- 金叉死叉在 0 轴附近更可靠
- 背离信号比金叉死叉更可靠

## KDJ (随机指标)

### 组成
- **K 线 (快线)**: 快速随机指标
- **D 线 (慢线)**: K 线的移动平均
- **J 线 (超快线)**: 3K - 2D，最敏感

### 数值范围
- **超买区**: K/D/J > 80，可能回调
- **超卖区**: K/D/J < 20，可能反弹
- **徘徊区**: 20-80，趋势延续

### 信号解读

| 形态 | 信号 | 含义 |
|------|------|------|
| K > D > 80 | 🔴 超买 | 短期可能回调 |
| K < D < 20 | 🟢 超卖 | 短期可能反弹 |
| K 上穿 D (金叉) | 🟢 买入 | 尤其在超卖区更可靠 |
| K 下穿 D (死叉) | 🔴 卖出 | 尤其在超买区更可靠 |
| J > 100 | 🔴 严重超买 | 强烈回调信号 |
| J < 0 | 🟢 严重超卖 | 强烈反弹信号 |

### 使用技巧
- KDJ 适合震荡市，趋势市容易钝化
- J 线最敏感，K 线次之，D 线最稳
- 周线 KDJ 比日线更可靠

## RSI (相对强弱指标)

### 基本原理
RSI 通过比较一段时期内的平均收盘涨数和平均收盘跌数，来分析市场买卖盘的意向和实力。

### 数值范围
- **RSI > 70**: 超买区，可能回调
- **RSI < 30**: 超卖区，可能反弹
- **RSI 50**: 多空分界线

### 常用周期
- **RSI(6)**: 短期，敏感
- **RSI(12)**: 中期，常用
- **RSI(24)**: 长期，稳定

### 信号解读

| 形态 | 信号 | 含义 |
|------|------|------|
| RSI > 70 | 🔴 超买 | 考虑减仓 |
| RSI < 30 | 🟢 超卖 | 考虑建仓 |
| RSI > 80 | 🔴 严重超买 | 强烈回调信号 |
| RSI < 20 | 🟢 严重超卖 | 强烈反弹信号 |
| 顶背离 | 🔴 看跌 | 价格新高，RSI 未新高 |
| 底背离 | 🟢 看涨 | 价格新低，RSI 未新低 |

## 成交量 (Volume)

### 基本规律
- **量增价升**: 🟢 健康上涨
- **量增价跌**: 🔴 主力出货
- **量缩价升**: 🟡 上涨乏力
- **量缩价跌**: 🟡 下跌趋缓
- **天量天价**: 🔴 见顶信号
- **地量地价**: 🟢 见底信号

### 成交量均线
- **5 日均量线**: 短期成交活跃度
- **10 日均量线**: 中期成交活跃度
- 成交量上穿均量线：🟢 活跃信号
- 成交量下穿均量线：🔴 萎缩信号

## 综合应用

### 多指标共振

| 组合 | 信号强度 | 说明 |
|------|----------|------|
| 3 个以上指标同向 | ⭐⭐⭐⭐⭐ | 强烈信号，可靠性高 |
| 2 个指标同向 | ⭐⭐⭐⭐ | 较强信号 |
| 指标相互矛盾 | ⭐⭐ | 观望为主 |

### 典型买入信号组合
1. ✅ MA 多头排列 + MACD 金叉 + KDJ 低位金叉
2. ✅ RSI 底背离 + 成交量放大 + 突破关键价位
3. ✅ 股价站上 MA20 + MACD 上穿 0 轴 + 成交量持续放大

### 典型卖出信号组合
1. ❌ MA 空头排列 + MACD 死叉 + KDJ 高位死叉
2. ❌ RSI 顶背离 + 成交量萎缩 + 跌破关键价位
3. ❌ 股价跌破 MA20 + MACD 下穿 0 轴 + 利空消息

## 注意事项

⚠️ **技术指标的局限性:**
1. 滞后性：指标基于历史数据，有滞后
2. 骗线可能：主力可能制造假信号
3. 震荡市有效，趋势市可能钝化
4. 需结合基本面、消息面综合判断

✅ **正确使用姿势:**
1. 多指标共振更可靠
2. 长周期信号比短周期可靠
3. 结合成交量验证
4. 设置止损，控制风险
5. 不盲目迷信单一指标
